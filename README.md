PW Merchant API is a professional WooCommerce integration designed to help merchants connect their WordPress store to their own Google Merchant Center account.

The plugin enables merchants to submit and update WooCommerce product data, select an accessible Merchant Center account, and review product processing results directly from the WordPress administration panel.

## Key features

- Connect Google Merchant Center with a secure Google OAuth flow
- Select an accessible Merchant Center account
- Submit WooCommerce products to Google Merchant Center
- Update existing product information
- Review product processing results
- Display product statuses and reported issues
- Manage product synchronization from WordPress
- Reduce repetitive product feed management work
- Improve visibility into Merchant Center product issues
- Provide a user-friendly WooCommerce management experience

## Who is PW Merchant API for?

PW Merchant API is designed for:

- WooCommerce store owners
- E-commerce administrators
- WordPress agencies
- Google Shopping specialists
- Digital marketing agencies
- Businesses managing product data in Google Merchant Center

## How it works

1. Install PW Merchant API on a WooCommerce website.
2. Start the Google connection from the WordPress administration panel.
3. Sign in with the Google account that has access to Merchant Center.
4. Review and approve the requested Google permission.
5. Select an accessible Merchant Center account.
6. Submit or update WooCommerce product data.
7. Review processing results and product issues in WordPress.

## Privacy and security

PW Merchant API uses Google account data only to provide the Merchant Center features explicitly requested by the authenticated user.

The application does not use Google user data for advertising, does not sell Google user data and does not share it with unrelated third parties.

Sensitive credentials, access tokens, OAuth secrets, license keys and Merchant Center account identifiers must never be posted publicly in GitHub issues or discussions.
