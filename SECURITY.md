# Security Policy

PW Feed takes the security of PW Merchant API, its users and connected services seriously.

This repository contains public product information and documentation. It does not distribute the commercial plugin source code, service credentials, licensing components or private infrastructure.

## Reporting a security issue

Do not report suspected security vulnerabilities through public GitHub issues, discussions, comments or screenshots.

Please send security reports privately to:

support@pwfeed.com

You can also use the official PW Feed support page:

https://www.pwfeed.com/support.html

Use the subject:

```text
Security Report – PW Merchant API
