# PW Merchant API Support

Thank you for using PW Merchant API.

This repository provides public product documentation, general discussions, bug reporting and feature suggestions.

## Before requesting support

Before submitting a support request:

1. Confirm that WordPress and WooCommerce meet the product requirements.
2. Confirm that PW Merchant API is updated to a supported version.
3. Review the available product documentation.
4. Check whether the same issue has already been reported.
5. Record the steps required to reproduce the problem.
6. Remove all sensitive information from screenshots and error messages.

## GitHub Issues

Use GitHub Issues for reproducible, non-sensitive software problems.

When opening an issue, use the provided Bug Report template and include:

- PW Merchant API version
- WordPress version
- WooCommerce version
- PHP version
- Steps to reproduce the problem
- Expected result
- Actual result
- Sanitized error messages

Do not use GitHub Issues for account-specific, licensing, payment, OAuth credential or security matters.

## Feature requests

Use the Feature Request template to suggest:

- New product management features
- WooCommerce workflow improvements
- Merchant Center integration improvements
- Synchronization options
- Reporting enhancements
- Documentation improvements

## Private support

Use the official PW Feed support channel for:

- License and payment questions
- Account-specific assistance
- Google OAuth connection problems involving private information
- Merchant Center account-specific problems
- Security reports
- Requests containing private store information

Official support page:

https://www.pwfeed.com/support.html

Support email:

support@pwfeed.com

## Sensitive information

Never publish the following information on GitHub:

- Passwords
- Verification codes
- OAuth client secrets
- Access or refresh tokens
- API keys
- License keys
- Merchant Center account identifiers
- Customer information
- Database credentials
- Hosting credentials
- Private store or product identifiers
